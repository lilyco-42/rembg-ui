# E03：商品图工作台独立原型（可直接转发）

你负责可演示的布局原型，Codex 负责接入业务。基线 rembg-ui 88646de，保留原生 HTML/CSS/JS。多人协作，不得覆盖现有业务。

唯一写入范围 `design/workbench/`：index.html、styles.css、可选 demo.js、README.md。禁止修改 web/、安装框架或依赖、接网络 API、加支付/登录/遥测、push 或部署。

布局需求：
1. 选图与输出规格；批次摘要；当前图片的原图/透明结果对比；可展开商品图预览。
2. 区分等待、处理中、失败、未确认、已确认。失败项展示错误及重试占位；明确“原型，不执行推理”。
3. 默认“只导出已确认”，下载交付包按钮展示数量；不能暗示未做功能已经上线。
4. 1280px 桌面与390px手机可用，无横向溢出；语义label、可见键盘焦点、清晰对比度。仅用键盘能访问主要控件。
5. 空状态、单张、十张、全失败各一个切换场景。仅使用内联自制占位图或明确有权素材，无第三方字体/CDN。

第一步先给桌面/手机布局说明和截图，再实现原型。可用静态演示数据，不得在演示数据上写真实质量/耗时/收入。

交付：文件、启动方式、验证的视口与浏览器、截图路径、键盘验证结果、未测试点。无浏览器执行能力则如实写未测，不能编造截图。Codex 会抽取布局接入正式 web/index.html，不直接把整个原型覆盖生产页面。
