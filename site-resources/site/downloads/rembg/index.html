如何批量抠图？

  1. 解压并打开。把 ZIP 完整解压到一个文件夹，再运行里面的 rembg-ui.exe，在自动打开的本机浏览器页面中操作。不要直接在压缩包中运行，也不要只复制 EXE。
  2. 选择整个文件夹。在「商品图工作台」点击「选择整个文件夹」，把图片加入批量队列；也可以多选图片或拖入多张。非图片文件会被跳过。
  3. 选择输出效果。只想保留原尺寸透明 PNG，可关闭「统一商品图」；需要统一尺寸时，在「交付规格」里选择画布、背景和格式。透明背景请选择 PNG 或 WebP。
  4. 开始批量处理。点击「开始 / 继续 / 重试失败项」。首次使用模型请等待下载完成；处理过程中可查看成功、失败和待处理数量。
  5. 检查并保存。检查结果后点击「下载交付 ZIP」。ZIP 只包含已完成且符合导出筛选的图片；失败项可重试，任务清单记录本批处理状态。

每批数量与使用额度以客户端显示的试用或授权方案为准。自动去背景可能需要手动修边，复杂图片请逐张检查结果。

下载与更新常见问题

旧版没有「选择整个文件夹」怎么办？

关闭旧程序，在新的文件夹中解压本站完整包，再运行新目录中的 EXE。确认打开的是该程序新启动的页面；有新版时可从官方更新记录核对后下载。

下载后需要联网吗？

首次使用所选模型需要联网下载模型文件；已经下载的模型用于本机处理。网络和模型下载失败时按客户端提示处理，不要把模型下载进度当成正在抠图。

如何核对文件？

Windows PowerShell 中执行 Get-FileHash .\Rembg-UI-windows.zip -Algorithm SHA256，把结果与上面的 SHA-256 对比。文件大小和摘要用于确认下载一致性。

需要 macOS、Linux 或 Android 版？

请查看项目官方 Releases，按系统选择文件。本站此处的 ZIP 是 Windows x64 版。

还需要手机投屏或 ADB？

scrcpy 官方 Windows 完整包内含 ADB；独立 Android Platform-Tools 提供 Google 官方入口。
