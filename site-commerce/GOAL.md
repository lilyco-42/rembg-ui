# Lain42 商业网站目标

2026-10-01，按用户“开始做网站、评估被动收入、重新规划 goal”调整。

**把 lain42.top 做成能展示成果、接到具体咨询、销售可重复交付数字产品的网站。先上线可靠的商品图入口，用真实订单验证需求，再把重复工作做成可自助使用和购买的模板、工作流包与软件授权，逐步降低每笔销售的新增人工。** Agent 和 WASM 服务于交付。

本轮近期结果：网站统一入口能正常引导用户体验、整理需求、联系工作室与查看授权；每一步说明是否提交、下单和付款；CI 验证通过后可回滚上线。长期业务方向：有明确客户、可重复交付、真实利润为正的创作工具与数字产品，不承诺无需经营的收入。

“被动收入”指降低每笔销售新增人工的收入，而非无人维护。优先评估可重复交付的规格／工作流包，其次稳定的软件授权，再次原创角色素材。人工服务是需求验证与现金流试验。

贡献利润 = 实收 - 退款 - 支付／API／存储直接成本 - 获客与交付人工。另计开发、内容维护、支持和授权成本；免费促销模型不用于长期成本承诺。真实 ROI 尚未知。

保留账号隔离、积分账本和管理员入口；不绑定私人 A7A；不修改余额或制造付款，不伪装自动接单。所有软件构建与测试只走 GitHub Actions，门禁未通过不部署。

本轮验收：无需登录生成、复制、下载询价资料；无自动上传；修改输入不会复制旧需求；内容按文本渲染；手机无横向溢出；素材许可、尺寸、数量有界；软件授权与人工服务清晰区分。

客户试单属于经营验收，不能用 CI 或自测账户代替真实客户付款。
