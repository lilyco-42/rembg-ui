# Lain42 商品图商业入口

本目录只维护商品图咨询入口，以及首页、购买页、公共导航中的相关链接。公共页面基线来自 2026-10-01 的线上静态文件；不是整个网站后端，也不包含任何账户数据库或凭据。

业务边界：页面生成本地询价资料，用户另行通过微信／QQ 联系工作室。没有调用接单或收款 API。参考预算不作为已确认报价。现有积分兑换与软件授权代码保持原样。

构建与测试只运行 GitHub Actions `Validate Lain42 commercial website`。执行纯模块校验、Chromium 交互、360／390／1280px 布局、深浅色、剪贴板失败、下载与刷新隔离场景。浏览器隔离检查只覆盖新需求单，不代表整个网站账户系统已完成隔离验收。

CI 成功后生成 `lain42-commercial-site` 静态产物和浏览器证据。只有部署脚本中明确列出的文件会发布；其他网站、管理后台、数据库和支付服务不在发布范围。

## 发布与恢复

`deployment-baseline.json` 保存此次读取的线上首页、购买页和公共脚本 SHA-256。发布前再次比较，发现线上文件变更即停止并重新合并，不覆盖别人的更新。

使用 CI 产物，先保存旧文件到网站目录之外，再逐文件原子替换。发布脚本保存回滚清单，新目录和新文件仅在通过检查后公布。不要把备份、账户文件或部署日志放在公开网站目录。

新路径 `/product-images/index.html`。首页主按钮、产品卡、购买页提示和公共导航都链接这里。使用已有 `/assets/studio.css`，不替换全站样式。

生产静态服务器不自动将新目录映射到 `index.html`，因此入口使用明确的文件地址。CI 也验证该地址；不假设开发预览服务器的目录解析行为在线上存在。

经营待办见 [GOAL.md](GOAL.md)。收款、试单、样图质量与模型商用条件由经营验收记录；CI 不能代替真实订单。
